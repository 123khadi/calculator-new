App Description & Core Features

A modern scientific calculator designed to perform essential mathematical operations, complex trigonometric functions, and logarithmic equations directly in your web browser.

  • Standard Arithmetic: Basic operations including addition, subtraction, multiplication, division, percentages, and decimals.
  • Advanced Mathematics: Square roots (√x), exponents (xy, x2), factorials (n!), and reciprocal functions (1/x).
  • Trigonometry: Sine (sin), cosine (cos), tangent (tan), and their inverses (sin-1, cos-1, tan-1) supporting both DEG (Degrees) and RAD (Radians) modes.
  • Logarithmic & Exponential: Natural log (ln), base-10 log (log), mathematical constants (π, e), and exponential functions (ex).
  • Calculation History & Memory: Live expression preview with real-time error handling, memory store/recall (M+, M-, MR, MC), and a log of past calculations.

User Guide & Controls

Control Group Buttons / Keys Purpose
System Controls AC, DEL, DEG/RAD Clear all inputs, delete the last character, or switch angle measurement modes.
Memory Keys MC, MR, M+, M- Clear memory, recall stored values, or add/subtract from the current memory total.
Functions sin, cos, tan, log, ln, √ Apply scientific operations to the current input or expression.
Constants π, e Insert exact mathematical constants into equations.
